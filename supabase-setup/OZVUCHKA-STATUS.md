Рабочие файлы в `private/audio/` **не тронуты**, сайт и генератор видео работают

## Зачем это делалось

Синтез читал цифры неровно: «Урок 1» выходил то «урок один», то «урок первый»,
а «3D» произносилось по буквам латиницей. Текст, который уходит в озвучку,
теперь проходит через `speakable()` в `lesson-video.html` — цифр там не остаётся
вообще, только слова («Урок пятый», «Видео и три дэ»). На экране при этом
по-прежнему «Урок 1» и «3D»: правится исключительно произносимое.

Старые mp3 записаны по прежнему тексту, поэтому их и нужно перезаписать.

## Что уже готово

Уроки **2, 3, 5, 7, 9, 10, 11, 13** — в `private/audio/new/urok-NN.mp3`.

Осталось: **1, 4, 6, 8, 12, 14–28** (двадцать штук).

## Как доделать

Параметры синтеза, которыми записаны готовые восемь (менять нельзя, иначе голос
разъедется между уроками):

- модель: `qwen_audio_tts`
- `voice_type`: `preset`
- `voice_id`: `e5666b9c-99a2-4fac-8b4e-abee078b186d` (это голос Vlad; по имени
  сервис голос не принимает, только по этому идентификатору)
- `language`: `ru`, `format`: `mp3`
- `instruction`: `Спокойный мужской голос, обучающий тон, ровный темп, чёткая дикция.`
  (у поля жёсткий лимит 128 знаков — длиннее сервис отклоняет запрос)

Текст урока берётся не из файла, а собирается кодом. Открыть `lesson-video.html`
на локальном сервере и выполнить в консоли:

```js
buildSlides(N).map(s => s.voice).filter(Boolean).join(' ')
```

где `N` — номер урока. Это и есть готовый текст для синтеза.

**Отправлять партиями по четыре.** Партия из одиннадцати наполовину отваливается
с ошибкой `429 rate_limit_reached`; четвёрки проходят стабильно.

## Последний шаг, без которого нельзя переключаться

Когда все 28 файлов будут в `new/`:

1. Заменить ими файлы в `private/audio/`.
2. **Пересчитать длительности и вписать их в `lesson-audio.js`.** По этим числам
   считается, сколько держать каждый слайд (см. `lesson-video.html`). Если файлы
   заменить, а длительности оставить старые, слайды разъедутся со звуком.

Длительности снимаются так:

```
ffprobe -v error -show_entries format=duration -of csv=p=0 "private/audio/urok-01.mp3"
```

Менять файлы частично нельзя: половина уроков с новыми длительностями и половина
со старыми — это гарантированный рассинхрон. Либо все 28, либо ни одного.
